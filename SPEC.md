# WhisperStorm — Specification

Product and design specification. For installation and usage see [README.md](README.md); for contributor/agent guidance see [CLAUDE.md](CLAUDE.md); for the history of past bugs and their root causes see [TASK.md](TASK.md). The original (German) build prompt is kept in [PROMPT.md](PROMPT.md).

## Goal

A native macOS menu-bar app for system-wide dictation. A global hotkey records the microphone, the audio is transcribed **entirely on-device** (or by a local OpenAI-compatible server), and the text is pasted into the focused app. No cloud calls.

## Non-goals (v1)

- No cloud speech-to-text.
- No streaming/word-by-word insertion — text is inserted after recording stops.
- No LLM post-processing or formatting of the transcript.
- No App Store release, no notarization.

## Tech stack

- Swift 5.10+, SwiftUI, macOS 14+, Apple Silicon.
- Menu-bar app: `MenuBarExtra`, no Dock icon (`LSUIElement = true`).
- Project generated by XcodeGen from `project.yml`; built with `xcodebuild`, no manual Xcode steps.
- Audio: `AVAudioEngine` input tap, downsampled to 16 kHz mono Float32 PCM.
- Global hotkey: [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts).
- Speech-to-text: [WhisperKit](https://github.com/argmaxinc/argmax-oss-swift) (CoreML) or an OpenAI-compatible HTTP server.
- Code, comments, identifiers and UI strings are English. Transcription handles German and English (auto-detect or fixed).

## Architecture

```
project.yml              XcodeGen manifest (targets, packages, entitlements, Info.plist)
Sources/
  WhisperStormApp.swift  @main: MenuBarExtra + Settings scenes
  App/                   Coordinator (dictation flow), settings, hotkey, state, control socket
  Audio/                 AVAudioEngine capture (16 kHz mono), CoreAudio device discovery
  Transcription/         TranscriptionProvider protocol, WhisperKit + OpenAI-compatible providers, model manager, WAV encoder
  Insertion/             Clipboard + synthesized Cmd+V (Accessibility)
  Overlay/               Non-activating NSPanel + 60 fps waveform (TimelineView/Canvas)
  Onboarding/            Permission traffic lights + deep links
  MenuBar/, SettingsUI/  Menu and settings views
```

- `DictationCoordinator` is the `@MainActor` orchestrator: hotkey → audio capture → transcription → insertion. New recording triggers hook in here.
- State flows one way: the coordinator mutates `AppState.phase` (`idle` / `recording` / `transcribing` / `success` / `error`); menu-bar icon and overlay observe it.
- `AudioLevelStore` is deliberately not `@Published` (buffer-rate updates would cause a SwiftUI invalidation storm); the overlay polls it at 60 fps.
- Settings persist through `AppSettings` (UserDefaults-backed `@Published` properties).

### Transcription providers

`TranscriptionProvider` is an async protocol (16 kHz mono Float32 PCM in, text out) with two implementations, selected in Settings:

1. **`WhisperKitProvider`** (default) — an `actor` caching the loaded CoreML pipeline, reloaded only when the model variant changes. A model manager downloads tiny / base / small / large-v3-turbo (default `small`, recommended `large-v3-turbo`) to `~/Library/Application Support/WhisperStorm/models` with progress UI.
2. **`OpenAICompatibleProvider`** — POSTs WAV (multipart/form-data) to `<baseURL>/v1/audio/transcriptions` with a configurable model name. Works with local Docker servers such as a `speaches` (faster-whisper) container. Docker Model Runner currently serves LLMs only; once it offers audio endpoints, the same provider works unchanged.

`prepare()` is split from `transcribe()` so the UI can show a "Preparing model…" state during the expensive one-time CoreML load. Do not fold setup back into `transcribe()`.

Errors (server unreachable, model not loaded, …) are never silent: they appear in the overlay (`AppState.phase = .error`) **and** as a user notification.

## Features and acceptance criteria

### 1. Hotkey dictation

- Configurable global shortcut (default ⌥ Space), working in every app.
- Two modes: **Toggle** (press to start, press again to stop and transcribe — default) and **Push-to-talk** (hold to record, release to transcribe; optional "tap to toggle" for taps shorter than 0.3 s).
- Esc while recording cancels: nothing is inserted, the clipboard is untouched.

### 2. Result insertion (text field and clipboard)

- After transcription the text is (a) written to the clipboard — and stays there, the previous contents are not restored — and (b) pasted into the focused app by setting `NSPasteboard` and posting Cmd+V as a `CGEvent`.
- Requires the Accessibility permission. The overlay must never steal focus from the target app.
- Edge case: no focused text field or paste fails → the text is still on the clipboard and a "Copied to clipboard" notification is shown.

### 3. Listening overlay

- Borderless, non-activating floating `NSPanel`, centered at the bottom of the active screen; rounded dark glass.
- Waveform: SwiftUI `TimelineView` + `Canvas` at 60 fps, about 40–60 bars driven by RMS/peak levels from the tap, smoothed with an attack/release envelope.
- Palette: horizontal gradient neon cyan `#00FFF7` → magenta `#FF2BD6` → violet `#7A2BFF`, neon glow via a blurred duplicate layer, subtle scanlines.
- States: **idle** — near-flat line that gently "breathes"; **speaking** — amplitude follows loudness; **transcribing** — shimmer/pulse; **done** — short bright flash, then fade-out; **error** — red glitch effect plus error text.

### 4. Microphone selection

- Settings and the menu-bar menu list all audio inputs (CoreAudio discovery); the choice is persisted and set as the `AVAudioEngine` input.
- If the selected device disappears: fall back to the system default and notify.

### 5. Menu bar and settings

- Menu-bar icon reflects status (idle / recording / transcribing).
- Menu: Start/Stop Dictation, Copy Last Transcript, Microphone submenu, Settings, Setup Assistant, Quit.
- Settings tabs: **General** (hotkeys, mode, language Auto/DE/EN, overlay look, launch at login via `SMAppService`), **Microphone**, **Model** (provider choice; WhisperKit model list with download status; base URL + model name for the OpenAI-compatible provider).

### 6. Permissions and onboarding

- `NSMicrophoneUsageDescription` in `Info.plist`.
- First-run Setup Assistant checks Microphone and Accessibility (`AXIsProcessTrustedWithOptions`), shows both as traffic lights and deep-links into the matching System Settings panes. It states clearly that insertion does not work without Accessibility.

## macOS constraints (non-obvious, already caused bugs)

- **Not sandboxed** (`ENABLE_APP_SANDBOX: NO`). `CGEvent` posting and `AXIsProcessTrusted()` do not work in a sandbox. Hardened Runtime is on.
- **Signature stability is load-bearing.** macOS TCC binds the Accessibility grant to the app's code signature. `project.yml` signs with a stable self-signed identity (`WhisperStorm Dev`) created by `scripts/setup-signing.sh`. Ad-hoc signing changes the cdhash on every build, which silently invalidates the grant: dictation still works, but the transcript only reaches the clipboard.
- **Insertion is best-effort with a clipboard fallback.** macOS silently drops synthetic keystrokes from untrusted processes — there is no error, so a posted event is never assumed to have succeeded. `TextInserter` reports a `clipboardOnly` outcome when Accessibility is untrusted, Secure Keyboard Entry is active, or nothing is focused.
- **The overlay must never steal focus** — it stays a non-activating `NSPanel`, otherwise paste-into-focused-app breaks.

## Known limitations (by design in v1)

- No streaming insertion; text appears after you stop recording.
- No punctuation or LLM post-processing.
- Secure input fields (password fields, terminals with Secure Keyboard Entry) block synthetic keystrokes; the transcript stays on the clipboard.
- Launch at Login may fail for builds run from the build folder (`SMAppService` prefers `/Applications`).
- The first transcription after selecting a new model waits for one-time CoreML specialization.
- Whisper models occasionally hallucinate short filler phrases on silent or very quiet recordings.
