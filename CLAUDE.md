# CLAUDE.md

macOS menu-bar dictation app; transcription strictly on-device, no cloud calls.

- Product intent and non-goals: `PROMPT.md` (source of truth). Before touching insertion or signing: read `TASK.md` (past bugs, root causes).
- `WhisperStorm.xcodeproj/` is generated by XcodeGen and gitignored: edit `project.yml`, then `xcodegen generate`.
- Tests: `xcodebuild test -project WhisperStorm.xcodeproj -scheme WhisperStorm -derivedDataPath build -destination 'platform=macOS'` (unhosted `WhisperStormTests`, compiles only the units listed in `project.yml`); `swift test --package-path Packages/WhisperStormTranscription`.
- Transcription core (`TranscriptionProvider`, WhisperKit, OpenAI-compatible) lives in the local package `Packages/WhisperStormTranscription` (macOS 14 + iOS 17); only it depends on WhisperKit.
- Once per machine: `./scripts/setup-signing.sh`. Build & run: `xcodegen generate && xcodebuild -project WhisperStorm.xcodeproj -scheme WhisperStorm -configuration Release -derivedDataPath build build && open build/Build/Products/Release/WhisperStorm.app`
- Insertion diagnostics: `~/Library/Logs/WhisperStorm.log` (unified log proved unreadable).

## Invariants
- New recording triggers hook into `DictationCoordinator`, not audio or transcription layers.
- Keep expensive setup in `TranscriptionProvider.prepare()`, never in `transcribe()` (drives the "Preparing model…" state).
- `AudioLevelStore` stays non-`@Published` (buffer-rate updates → SwiftUI invalidation storm); overlay polls it via `TimelineView`.
- No App Sandbox: `CGEvent` posting and `AXIsProcessTrusted()` fail inside it.
- Sign with stable identity `WhisperStorm Dev`: TCC binds Accessibility to the signature; ad-hoc signing changes cdhash per build and insertion silently degrades to clipboard-only.
- `TextInserter`: clipboard first (no restore, by design), then synthetic Cmd+V; `clipboardOnly` outcome when untrusted, Secure Keyboard Entry, or nothing focused. macOS silently drops synthetic keys from untrusted processes: never assume a posted event succeeded.
- Overlay stays a non-activating `NSPanel`; stealing focus breaks paste.
- Code, comments, identifiers, UI strings English; transcription handles German and English.
- Errors surface in overlay (`AppState.phase = .error`) and as notification (`NotificationManager`).
